Reel Drive Backup privacy policy

This policy describes the private, single-user Reel Drive Backup tool.

Google access and use

The tool uses Google authorization to upload encrypted video files, find its destination folder, and check uploaded files. The Google Drive permission it requests permits access to all Drive files; the tool uses that permission for its backup workflow.

Storage and processing

Authorization credentials are kept in a private configuration on the operator's server. Video contents and filenames are encrypted before upload. File information, backup status and error records are used to run and troubleshoot the backup. Downloaded videos may be retained on the server while an upload is waiting or being checked.

The tool sends encrypted files and required file information to Google Drive to provide the backup. Authorized maintenance may process credentials, file information and backup records to configure, verify or repair the tool. Google and the server provider process data under their own applicable terms and policies.

This website does not display the archive or provide access to it.

Control and deletion

The operator can revoke the tool's access in Google Account settings and delete backup files from Google Drive. Revoking access stops future access; it does not delete files already saved or local records. Those can be deleted separately by the operator.

Contact

For questions about this tool, use the contact information on this website's main page.
